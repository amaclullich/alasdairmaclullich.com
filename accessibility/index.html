Accessibility

Accessibility statement

This website is intended to be usable with a keyboard, screen magnification, reflow and assistive technologies.

Measures taken

The site aims to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at Level AA. Pages use semantic headings, labelled navigation, visible keyboard focus, skip links, descriptive link text and text alternatives for meaningful images. Layouts are designed to reflow on small screens and at browser zoom.

The site does not depend on animation, audio or complex interactive controls. Optional analytics can be accepted, rejected or changed using keyboard-operable controls. A print stylesheet removes navigation and other screen-only elements from printed pages.

Report a barrier

If any page or document is difficult to use, please use the contact page and include the page address, the problem encountered and, if you are comfortable doing so, the browser or assistive technology involved. I will try to provide the information in an accessible alternative and correct the underlying issue.
